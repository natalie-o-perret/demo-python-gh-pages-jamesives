# demo-python-gh-pages-jamesives

Tiny Sphinx site deployed with `JamesIves/github-pages-deploy-action`.

Single workflow job with `contents: write`, pushes the built site to the
`gh-pages` branch. Compare against
[`demo-python-gh-pages-official`](https://github.com/natalie-o-perret/demo-python-gh-pages-official).
